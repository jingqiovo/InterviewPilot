# InterviewPilot

> 你的 AI 面试陪练。让每一次练习，都像真实面试。

上传简历后，系统会根据你的经历生成针对性的面试问题，并模拟真实面试过程，帮助你提前发现表达、逻辑和知识上的问题。

当前版本使用模拟数据展示完整流程，后续可接入真实大模型 API。

**项目地址**：<https://github.com/jingqiovo/InterviewPilot>

---

## 为什么做这个项目

做完 ResumePilot 之后，我发现很多求职者即使知道自己的简历问题，真正进入面试时依然会紧张。

很多问题平时觉得自己会回答。真正被面试官问到时，却不知道从哪里开始说。

后来我发现，大部分人缺少的并不是知识，而是练习。

现实里很难找到一个愿意长期陪你模拟面试的人。于是我做了 **InterviewPilot**，希望通过 AI 模拟面试的方式，让用户在正式面试之前，已经提前练习过很多次。

---

## 这个项目解决什么问题

- 面试前不知道该怎么准备
- 项目经历讲不清楚
- 技术问题知道答案，但表达不出来
- 缺少真实的练习环境
- 不知道自己的短板在哪里
- 每次面试结束无法复盘

---

## 核心流程

```
选择训练模式 → 上传简历 → AI 分析背景 → 生成专属问题 → 模拟面试 → 获得反馈 → 持续练习
```

---

## 核心功能

### 项目追问训练

根据项目经历生成深度追问。

例如：

- 为什么这样设计？
- 为什么选择这个方案？
- 遇到过什么问题？
- 如果重做一次会怎么优化？

---

### 技术面试训练

根据目标岗位生成技术问题。

涉及方向：

- React / TypeScript
- Agent / LLM
- AI 产品设计
- 前端工程化

---

### HR 行为面训练

模拟真实 HR 面试。

常见场景：

- 自我介绍
- 职业规划
- 优缺点
- 团队协作
- 压力处理

---

### AI 分析过程展示

展示 Agent 分析步骤，让用户知道：

- 正在分析什么
- 当前进行到哪一步
- 为什么生成这些问题

---

### 模拟面试

AI 不只是出题，还会根据用户回答继续追问，尽量模拟真实面试场景。

---

### 结果反馈

面试结束后生成反馈报告，包含：

- 综合评分
- 表达能力
- 技术能力
- 逻辑能力
- 改进建议

---

### 成长记录

保存历史训练结果，帮助用户观察长期成长趋势。

## 设计思考

### 为什么先选择训练模式？

我希望用户打开产品后想到的是：**我要开始练面试了。**

而不是：**我要上传一个文件。**

所以训练模式放在整个流程最前面。

### 为什么保留追问机制？

真实面试最难的部分往往不是第一个问题，而是后面的追问。

因此产品不仅提供问题，还会根据回答持续追问。

### 为什么加入成长记录？

练习最大的价值不是一次高分，而是能够看到自己不断进步。

所以保留了训练历史和成长趋势。

## 技术栈

| 类别 | 选型 |
|------|------|
| 框架 | React 18 + TypeScript |
| 样式 | Tailwind CSS + 自定义动画 |
| 状态管理 | Zustand |
| 构建工具 | Vite |
| 图标 | Lucide React |

### 动画系统

- **入场动画**：stagger 错落、slide-up、scale-in、slide-in-bottom
- **状态动画**：pulse-dot 脉冲、heartbeat 心跳、cursor-blink
- **交互动画**：card-lift 悬停浮起、icon-lift、underline-expand 下划线
- **进度动画**：bar-grow 柱状生长、score-roll 分数滚动、typing-dot
- **全局细节**：按钮 hover 提升 + 阴影、输入框聚焦光晕、骨架屏 shimmer
- 支持 `prefers-reduced-motion` 无障碍降级
