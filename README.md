# InterviewPilot

你的 AI 面试陪练。让每一次练习，都像真实面试。

> 本版本使用模拟数据展示完整的 AI 面试陪练体验流程，涵盖从选择训练模式、上传简历、AI 生成专属问题、模拟面试对话到反馈结果和成长记录的全部交互节点。后续可接入真实的语言模型 API。

---

## 为什么做这个项目

基于上一个项目进行扩展 上一个项目地址 https://github.com/jingqiovo/ResumePilot-AI
很多求职者在准备面试时有一个共同的问题。

他们看了很多面经。
背了很多答案。
甚至能完整复述"什么是闭包"、"什么是事件循环"。

但真到了面试现场，还是会紧张到说不出话。

因为面试不是知识测试。
是表达测试、压力测试、临场反应测试。

没有人能在第一次真实面试中表现得很好。
除非他已经在另一个地方练习过很多次。

但现实是：
- 朋友不可能每次都陪你练
- 专业教练价格昂贵
- 录播课程无法提供实时反馈

所以我做了 InterviewPilot。

一个会主动提问、追问、评估、反馈的 AI 面试陪练。
让你在真实面试前，已经"面试"过很多次。

---

## 这个产品解决什么问题

- 看了很多面经，但真到了面试说不出话
- 知道 STAR 法则，但不会在压力下使用
- 练习时没有反馈，不知道哪里需要改进
- 单次面试无法复盘，下次还是会犯同样的错
- 缺少持续的练习计划和成长记录

## 我的设计思考

这个项目最大的挑战不是让 AI 工作。

而是设计**人和 AI 的协作方式**。

什么时候 AI 应该主导？
什么时候人应该主导？
什么时候 AI 应该等待？
什么时候 AI 应该追问？

这是 AI 产品设计真正需要思考的问题。

## 产品功能

### 使用流程

```
选择训练模式 → 上传简历 → AI 分析 → 进入模拟面试 → 获得反馈 → 持续练习
```

- **选择训练模式**：项目追问 / 技术面试 / HR 行为面
- **上传简历**：让 AI 了解你的背景，定制专属问题
- **AI 分析**：把分析过程逐步展示给用户
- **模拟面试**：像真实面试官一样主动追问
- **结构化反馈**：评分 + 能力拆解 + 改进建议
- **成长记录**：训练次数、平均评分、能力趋势

### 核心功能

| 功能 | 说明 |
|------|------|
| 三种训练模式 | 项目追问 / 技术面试 / HR 行为面 |
| AI 简历分析 | 基于简历生成个性化面试问题 |
| 动态追问 | 根据用户回答生成下一个问题 |
| Agent 流程展示 | 把 AI 分析步骤逐步展示给用户 |
| 流式分析日志 | 实时显示 AI 思考过程 |
| 多维度评分 | 专业能力 / 沟通表达 / 问题解决 |
| 问题诊断 | 强项 / 待改进 / 机会点 |
| 改进建议 | 按优先级分类的可执行建议 |
| 成长曲线 | 训练次数 + 平均评分 + 能力趋势 |
| 历史记录 | 完整的练习记录管理 |

## 设计理念

**为什么从选择训练开始，而不是上传简历？**

用户进入产品的第一直觉应该是：
"我要开始练面试了。"

而不是：
"我要上传一个文件。"

所以首页的核心交互是"选择训练"，上传简历只是准备步骤。

**为什么需要成长曲线？**

练习最重要的不是单次成绩，是趋势。

如果第一次 65 分，第五次 80 分。
那就是真的进步。

成长曲线让用户看到自己的进步轨迹，激励持续练习。

**为什么整体视觉走克制路线？**

求职是一个严肃场景。
用户打开工具时其实带着一点焦虑。

太花哨的视觉会让人分心。
设计目标是让用户专注于"开始练习"。

## 技术实现

- **框架**：React 18 + TypeScript
- **样式**：Tailwind CSS + 自定义动画
- **状态管理**：Zustand
- **构建工具**：Vite
- **图标**：Lucide React
- **动画**：CSS Keyframes + Tailwind Transitions

### 动画系统

- **首页**：训练卡悬停浮起、Hero 渐入、准备区展开、成长柱状图渐入
- **分析页**：Agent 步骤状态切换、日志逐行出现、进度脉冲
- **面试页**：题目切换淡入、答案输入聚焦、提交按钮反馈
- **结果页**：分数数字滚动、卡片逐个进入、进度条动画填充
- **全局**：按钮悬停、链接下划线过渡、骨架屏呼吸
